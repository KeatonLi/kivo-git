# 0.5.4 最近提交体验

保留 Commit 侧栏的现有视觉，只优化最近提交的默认数量、展开空间和阅读连续性。

- 默认显示最近五条提交，移除 Show 3 / Show 5；已有三条默认值不会延续到新版本。整个区块仍可折叠。
- 收起时按内容占空间，普通侧栏可以同时看见五条；详情展开时提高可用高度，上限 420px / 48%，并给上方提交流程保留预算。短窗口通过列表滚动阅读。
- 展开标题最多两行；文件行至少 28px，保留 Git 文件颜色、文件名优先和完整路径提示。
- 预览与提交共用一个滚动区。展开靠下的提交时显示其详情；异步加载后照顾正在聚焦的文件或 History 入口。
- 手动拖拽的分隔线尺寸优先于自动布局；收起、重试、后台刷新保留提交草稿和选择。遵循系统减少动画设置。

## 验证

`npm run test:webview` 覆盖五条默认可见、旧状态迁移、展开后高度增加、收起复原、第五条键盘展开、十二文件预览、手动尺寸优先、240×420 短侧栏的提交按钮和键盘回返。同时保留 0.5.3 五项交互回归与完整 E2E。

主题与减少动画截图检查使用 `KIVO_CAPTURE_DIR=visual-audit npm run test:webview`。截图来自 Webview fixture；原生 Extension Development Host smoke 由 CI 验证，不等同于真实设备的完整手动体验验收。

## 冲突合并

本次不修改 Git 操作语义。现有流程由 Git 自动合并无冲突的部分，冲突文件可进入 VS Code 原生 Merge Editor；解决并暂存后继续，或中止当前 merge / rebase / cherry-pick / revert。真正冲突的结果仍由用户确认。
